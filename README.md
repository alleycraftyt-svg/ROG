# ROG

You can make mods of this game.

## Linux & Termux Installation and Setup

Follow these steps in your terminal to install the requirements and play the game.

### 1. Install Dependencies (Choose your system)

If you are using **Ubuntu, Debian, Linux Mint**, or derivatives:
```bash
sudo apt update && sudo apt install git python3 python-pip -y
```

If you are using **Fedora, Red Hat**, or CentOS:
```bash
sudo dnf install git python3 python-pip -y
```

If you are using **Arch Linux, Manjaro**, or derivatives:
```bash
sudo pacman -Syu git python python-pip --noconfirm
```

If you are using **Termux (Android)**:
```bash
pkg update && pkg install git python -y
```

---

### 2. Download the Game
Copy this command to clone the complete game repository to your device:

```bash
git clone https://github.com/alleycraftyt-svg/ROG
```

---

### 3. Run the Game
Enter the newly created folder and launch the game with this final command(theres to versions the esp and eng edition):

```bash
cd ROG && python3 ¨ROG(ESP).py¨
```
```bash
cd ROG && python3 ROG.py
```
