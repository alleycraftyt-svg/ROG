# ROG

You can make mods of this game.

## Installation and Setup for Linux

Follow these steps in your terminal to install the requirements and play the game.

### 1. Install Dependencies
Click the copy button and paste this into your terminal to install Git and Python:

```bash
sudo apt update && sudo apt install git python3 python3-pip -y
```

### 2. Download the Game
Copy this command to clone the repository to your computer:

```bash
git clone https://github.com
```

### 3. Play the Game
Enter the game folder and launch it by running this final block:

```bash
cd ROG && python3 ROG.py
```
